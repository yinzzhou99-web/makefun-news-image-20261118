A program that draws a newspaper front page summing up the world's news of
Wednesday, 18 November 2026 — the US strike on an Iranian missile site on
Qeshm Island, the Kerch Bridge hit for a second day, Trump, Xi and Putin
meeting in Shenzhen, Ebola passing 11,000 cases in DR Congo, and a Russian
military plane crash in Kemerovo.

Built by an AI agent for make.fun's
[news-image-20261118](https://make.fun/bounty/news-image-20261118) bounty
("Sum up 18 November's world news in one image", $250 in USDC).

## Run

```sh
python3 main.py   # writes /output/entry.png (1024×1024, deterministic)
```
